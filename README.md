# Finance Tracker API (Work in Progress)

REST API сервис для управления личным бюджетом, категоризации расходов и доходов. 

## Стек технологий
* **Язык/Фреймворк:** Java 17, Spring Boot (Web, Data JPA)
* **База данных:** PostgreSQL
* **Инфраструктура:** Docker, Docker Compose
* **Сборка:** Maven

## Текущий статус
Проект находится в стадии активной разработки.
